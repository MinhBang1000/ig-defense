# InteractionGuard Results

Keep this review archive separate from active experiment outputs. Paths below
match the locations regenerated under the code repository root.
Raw traces and fixed split/judge inputs are provided with the code repository.

| Path | Contents / regenerated by |
| --- | --- |
| `results/research_runner/dataset/` | Annotated episodes, splits, prefixes and training exports; Item 0. |
| `results/research_runner/training/` | Training settings, calibration and checkpoint metadata; Item 1. |
| `results/research_runner/configuration_stage1/` | Screen/Gate scores, routing and pending Audit requests; Item 2 Stage 1. |
| `results/research_runner/configuration_stage2/` | Final decisions, metrics and ASR; Item 2 Stage 2. |
| `results/research_runner/{baselines,channel_ablation,backend,threshold,benign}/` | Items 3, 4, 5, 6 and 7 respectively. |
| `results/research_runner/auditor_targeted/`, `data/auditor_targeted/` | Selected-case results and inputs; Item 8. |

Run from the code repository using `config/experiments.yaml`. Use a separate
output directory when rerunning to preserve this snapshot.

Weights, embeddings, worker logs and temporary runs are omitted. Local account
paths in metadata are replaced; traces, verdicts and numeric results are unchanged.
This is a review snapshot, not a resumable checkpoint bundle. Original manifests
record historical artifacts; `EXPORT_MANIFEST.json` records included/omitted files,
source/export SHA-256 hashes and redacted files. Do not treat automated path and
credential checks as a complete personal-data audit of trace contents.
